# **LebSpace -- Lebanese Social Media Platform**

LebSpace is a modern, full-stack social media platform, built using the MERN stack.\
It is designed specifically for Lebanese users, offering a smooth,
real-time, and secure social experience with a clean, modern UI and full
mobile responsiveness.

------------------------------------------------------------------------

## 🚀 **Features**

### 🔐 **User Authentication & Security**

-   JWT authentication
-   Public and private account modes
-   Block/unblock users
-   Delete account
-   Secure password hashing

### 👤 **Profile Management**

-   Edit profile (name, username, bio, profile picture)
-   View other users' profiles
-   Follow / Unfollow system

### 📝 **Posts & Stories**

-   Create posts with captions and images
-   Add daily stories
-   View stories of users you follow
-   Like/unlike posts
-   Comment on posts
-   See posts from people you follow

### 🔔 **Notifications System**

-   Receive alerts for:
    -   Likes
    -   Comments
    -   New followers
    -   Story views (optional)

### 💬 **Real-Time Chat**

-   Chat in real-time using **Socket.io**
-   Online/Offline user status
-   Read/unread message status
-   One-to-one chat system
-   Messages stored in MongoDB
-   Fast and responsive chat UI

### 👥 **Social Interactions**

-   Followers / Following system
-   Explore users
-   See what your friends posted recently
-   Activity feed

### 💻 **UI / UX**

-   Modern design
-   Responsive layout
-   Smooth animations and transitions

------------------------------------------------------------------------

## 🛠️ **Tech Stack**

### **Frontend**

-   React.js
-   React Router
-   Context API
-   TailwindCSS
-   Socket.io-client

### **Backend**

-   Node.js
-   Express.js
-   MongoDB + Mongoose
-   Socket.io
-   JSON Web Tokens (JWT)
